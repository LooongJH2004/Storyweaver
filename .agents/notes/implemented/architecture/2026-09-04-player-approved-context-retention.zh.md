# Agent Note: 玩家批准的上下文保留与原文回查

Status: implemented

[English](2026-09-04-player-approved-context-retention.md) | 中文

## 问题

固定近期窗口会静默移除未完成条件，整组覆盖的 Brief 会遗漏仍然重要的事实。世界摘要无法恢复从未写入摘要的细节；自动总结既增加请求开销，也无法证明改写后仍保留全部例外。

## 决策

Story 保存不可变来源位置、当时知情范围、稳定顺序、带修订的短记、提案及按读取者区分的原文固定状态。原文保留在 Session 日志、世界记录、实际感知或持久讨论中；旁白定位完整提交文本，已接受行动保留结构化字段。回查只选择当前索引及调用者有权读取的来源，按来源 id、字面关键词或场景分页读取完整内容。

导演和演员在正常提交中携带固定可选字段 `context_update`，本次 `$narration` 与 `$behavior:N` 引用在接受后解析。Host 在提交产生效果前拒绝缺失来源、越权、过期目标修订和导演代演员撤回承诺。已接受演员尝试幂等写入待审核提案。不可变的原始提交与玩家编辑的审核版本分别保留，恢复已接受尝试时不会误报编辑冲突或覆盖审核内容。提案本身不会激活短记、调用其他模型或授权裁剪。

玩家把来源处理单元、全部对应短记和归档理由一起审核。修订检查保证批量操作原子性，编辑、批准、拒绝和固定均为明确操作。事实、说法、承诺、条件、问题、线索、玩家走向和结果保留类型及来源；已解决和已撤回的后果仍进入上下文。明确替换会转移来源承接关系，缺少任一必要短记就恢复原文。Brief 更新局势与调度感知，事实和未决事项由已批准短记派生。

导演、演员和讨论默认 64/32/12 的窗口是近期最低保留范围。更早来源仍保留，直到对应读取者已获批短记承接或明确仅归档，且不存在重叠待审核单元或原文固定。世界、讨论和当前轮按来源 id 去重。各 Agent 基线按可见新增来源推进，默认 12 条或 24,000 增量字符；静态设定、配方和场景变化也会重建，合格原文只在重建时移出。其他角色的私有活动不会推进该读取者计数。请求日志保存实际保留统计，容量失败会停止，不静默丢弃历史。

全部保留状态进入 Story 运行检查点。撤回恢复当前来源索引，被替换 Session 历史仍可审计，但模型不能回查。重启从持久化版本 10 加载来源、提案与审批，并重建派生请求批次；可复用故事书保留独立格式。[固定工具与并行准备](2026-09-04-roleplay-source-continuity-and-fixed-tools.zh.md) 继续负责独立工具权限、记忆替换与并行准备，本记录接替其中的自动标记及历史裁剪决策。

## 考虑过的替代方案

**周期性或 token 触发总结。** 这会增加模型输入输出，并需要难以预测成本的触发条件。正常提交复用当前上下文，压缩进度由审核决定。

**自动激活短记或硬截断。** 两者都可能静默接受不完整替代。待审核原文持续存在，直到玩家批准完整单元；来源链接支持纠错，不宣称自动验证语义。

**动态工具列表或早期代表发言。** 动态工具定义改变请求前缀，每人一条代表发言也无法保留全部条件。独立固定工具与统一审批规则覆盖全部讨论来源。

## 后果

真实 Loader 回放使用正式 Storyweaver 导演和演员预设、持久化及 Controller API，仅脚本化外部模型响应，不启动浏览器。覆盖完整旁白回查、演员访问拒绝、待审核排除、明确批准、工具稳定性、请求统计与冷重启。领域及 AgentLoop 测试覆盖窗口溢出、部分及过期审核、固定、已解决事项替换、并行准备、取消、重试和历史撤回。组件快照覆盖审核侧栏，网页效果由用户验收。

未批准原文和有效短记可能持续增长至超过模型容量。审核与维护短记需要玩家投入，改写短记仍可能遗漏含义。来源索引与完整检查点也增加存储；本次没有向量检索、周期总结器、硬 token 上限或提供方缓存命中率保证。
