# Agent Note: 根据本地执行失败修正工具指导

Status: implemented

[English](2026-09-08-log-driven-tool-guidance.md) | 中文

## 问题

本次检查的独立故事在五个执行会话中有 51 次工具调用，其中 10 次被拒绝。错误包括 observe.state 缺失、重复嵌套 command、无效 JSON、重复键覆盖为无效空摘要、把身体姿势当作回合状态、复制状态定义时写错字段名、修正时遗漏思想内容、误用讨论阶段，以及把讨论摘要回合 ID 当作来源。这些是实际协议失败，不代表已完成虚构判断质量评测。

视角渲染器展示了证据校验器不接受的 discussion-turn ID。通用拒绝信息随后让一名角色在删除无效来源时也遗漏了必填思想内容。导演参数投影虽然展示必填字段，却缺少完整操作示例，也未说明非空文本限制。

9 月 9 日后续两次导演准备共有九次调用，其中四次被拒绝：已有明确的包装层警告，仍重复嵌套 command 或多写 JSON 右括号。第二次被接受的旁白还在人物检查账簿后编写该人物的对白，并将这段虚构披露投递给其他人物。因此需要简化正文操作，并具体区分观察结果、人物反应和主动披露。

## 决策

保留单次原子 NPC 提交与领域导演操作联合类型。世界结算通过单层 director_observe 工具暴露，其余操作由 director_command 承担。两者经同一受权限约束的执行回调、回执日志与释放路径注册。旁白指导说明客观结果、按受众区分的感知与后续演员调度，以检查线索为例，不虚构发言或散播私下发现。在对应 NPC 字段上区分：posture 是回合状态，每项 thoughts 必须有 content，已有状态更新省略 definition。自定义措辞与不可变版本保持不变，执行指导列出当前工具。

视角文本明确说明没有讨论席位的情况，并明确描述私下准备。讨论摘要保留发言者和正文，省略不可引用的回合 ID。来源错误指向已接收证据或个人记录，不扩大访问权限；阶段错误说明允许的修正。领域层仍然拒绝无效来源和准备期公开行为，不提交部分效果。

## 考虑过的替代方案

静默剥离无效字段或把讨论 ID 转为证据会掩盖模型错误或虚构来源。放宽准备期限制会发布私下规划。无需拆分全部导演操作：只有正文结算存在本次观察到的长参数重复包装错误。文学内容的创作权限仍由提示词指导；机械拒绝所有引语或人物指称，也会误伤合理的环境旁白和已接受行为引用。

## 影响

请求文本和工具定义发生变化，已有缓存前缀可能不同。这些修改不保证模型不再出错，也不代表已测得供应商模型错误率降低。额外指导消耗 tokens；普通回合仍省略可选字段。保存的自定义上下文配方仍可禁用讨论区段，固定工具策略与领域检查继续生效。

核心源码别名明确指向 index.ts，避免源码执行解析到旁边过期的 JavaScript 产物。真实 Loader 测试记录模拟供应商收到的 NPC 策略与工具，验证回滚和恢复隔离，并检查 system/user 配方消息分离。导演 schema 快照验证示例，拒绝脱敏的本地失败模式。讨论应用测试验证摘要 ID 被原子拒绝，实际收到的证据 ID 可正常提交。验证不推进真实玩家回合，也不调用付费供应商。

导演组合测试拒绝嵌套旁白、接受修正后的单层提交，验证只有四次成功准备写入产生回执，并继续执行人物回合，同时记录完整导演策略与工具定义。客户端测试只从未完成的单层参数中提取公开旁白，并保留旧记录的旁白渲染。这些测试验证协议与发布，不代表已测得模型文学判断的改善。

实现归属为 [NPC 协议](../../../../packages/story/roleplay-core/src/npc-protocol.ts)、[视角投影](../../../../packages/story/roleplay-core/src/perspective.ts)与[导演 schema](../../../../packages/experimental/actor/src/director-tool-schema.ts)。后续真实模型评测应区分首调成功与重试成功，并使用隔离故事。

本地导演第 8 回合对同一配角进行了三次创建尝试：先因 JSON 多余右括号失败，再因初始认知把新人物显示名填入 targetActorId 失败，第三次修正后成功。工具 schema 现提供可执行的创建示例和精确 ID 提示；策略区分自身／世界知识与识别另一个人物。领域拒绝信息点明无效引用、说明可省略字段，并保证不产生半成品人物。回归覆盖拒绝、修正与回执复用，不重复创建人物；这些检查不代表已测得真实模型错误率下降。
