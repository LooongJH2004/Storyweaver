# Agent Note: 配方角色与人物回合阅读

Status: implemented

[English](2026-09-08-recipe-roles-and-turn-reading.md) | 中文

## Problem

独立版默认将全部上下文模块设为 user。导演自造的思维模式标记没有保留参考项目的分析约束，推理语言偏好仅作为数据序列化。代码更新后，已有实例仍保留这些缺陷。外貌首字头像难以辨认，重复人物标题与嵌套折叠妨碍阅读，删除入口藏在次级导航里。

## Decision

默认设定和规则来源使用 system，玩家要求与末尾思维模式模块使用 user。导演采用参考项目的 `〖思维模式要求〗` 分析模式，演员沉浸约束保持不变。语言作为适用于每一步推理的明确指令。相邻同角色模块继续使用现有请求合并方式。

修复先修改配方草稿，再通过修订校验保存。它纠正内置模块全为 user 的默认值、补齐缺失默认来源，并仅替换完全匹配的错误导演文本。自定义内容、禁用状态、混合消息角色选择和已记录历史均保留。读取不修复存储。已发布故事书与现有实例配方分别归属。

每个已接受人物回合仅显示一次供玩家参考的主姓名与次级外貌描述，下面连续排列动作和对白，移除外貌首字头像。查看思考与当时上下文直接打开独立阅读窗口，包含请求步骤、可搜索消息、回应、参数和原始 JSON。历史输入仅来自已记录证据。侧栏在故事书和实例旁直接显示删除，确认窗口明确目标与保留版本的影响。

原生 dsh token 统计从完整技术回合投影，通过共享 TurnUsageDisclosure 组件展示。重试与工具步骤各计入一次，记录不完整时明确显示不可用。每回合请求次数呈现导演准备中的多个步骤。已记录思考、消息正文和工具参数分别成块，长块可原位展开。对白与动作卡片共用一次人物标题。来源编辑使用弹窗，新建或明确修复的配方可以独立调整导演提示词的顺序。

## Alternatives considered

**自动重写全部配方。** 这会抹去作者的有意选择，使历史请求无法重现。

**把模拟请求视为模型遵守约束的证明。** 模拟只能验证传输与持久化，不能验证实际生成的思考。独立的有界真实模型检查使用隔离存储中的虚构测试情节。

## Consequences

控制选择不能依赖场景出席。复用旁观视角的场景代演列表会导致新运行只剩旁观选项。查询分别提供完整未归档控制名单和即时代演名单，并标明是否在场。输入区解释未入场控制状态并阻止过早发言，选择操作不使角色自动入场。核心与浏览器回归从尚未建立场景的角色列表开始，验证接管以及随入场变化的回应权限；API 镜像同时覆盖切换运行后的迟到名单拒绝。

叙事重点与玩家控制权现在具有不同契约。主角仍是 characters 中的普通角色，由 protagonistActorId 引用；编辑器提供「添加主角」并说明不指定主角也合法。缺省、null 与空白值规范化为 null，普通角色创建不选定主角，非空但未知的角色 ID 仍被拒绝。AI 创作说明与创作指导保留这一选择。独立运行的 player-control/current 由明确玩家命令修改，与查看或临时代演角色分开。接管使旧执行失效，跳过待执行的私下准备而不制造玩家意图，拦截 Actor 开始和提交，并过滤导演误分派。讨论轮到受控人物时等待，支持玩家发言或明确保持沉默，并提供就近继续入口。存档导入与浏览器刷新保留控制权。核心回归覆盖接管/解除、迟到结果、准备、发言/让过与导演过滤；浏览器覆盖接管、刷新、解除。旁白获得相应指导，但结构化执行防线不能对任意自由文本提供语义保证。原始用户 JSON 与已有故事书版本不被改写。

群组准备已经使用冻结批次输入并发执行演员，但阅读界面此前只选取一个活动角色。群组卡投影已接受的就绪数量，并区分执行中与暂停准备；准备完成后保留可独立折叠的角色记录。存储的 attempt/版本坐标防止后续公开发言替换准备内容；旧记录使用首次公开回合回执边界。展开中的实时记录按需刷新，收起后停止。提交的私有立场与思考明确属于作者诊断。真实 Loader 测试挂起两个准备请求，先释放第二个，验证只接受一个准备且没有公开回合，再释放第一个并验证顺序发言。取消与外部写入限制仍由核心运行时测试覆盖。

作者导航提供常驻的返回剧情按钮。离开游玩时暂停阅读跟随，返回时恢复最后跟踪的位置，不再读取正文被作者页面替换后的共用滚动容器位置。未发送的引导仍保存在实例草稿存储中。Hook 测试覆盖暂停位置恢复、继续跟随与视图隔离；浏览器测试在窄屏中逐一进入四个作者快捷入口，返回后检查阅读位置与草稿不变。

游玩工具现在与标题共用吸顶导航容器，不再归属于随开场滚动的区域。场景人物入口在整个消息流中始终与其他工具一起可见。原生弹窗替代正文旁的吸顶侧栏，避免正文重排，并让长距离滚动后仍能打开人物列表。浏览器回归检查桌面和窄屏底部工具位置、弹窗开关时滚动与高度不变，以及 Escape 后焦点归还。

演员缓存排序是独立的显式编辑：稳定设定、判断和个人记录排在实时人物、状态与证据之前。只允许消息角色相同的相邻内置模块移动；自定义模块和思考指令作为边界。来源选择和记忆预算不变，历史请求仍回放原配方。新默认值采用此顺序；已有实例与作者书稿需要显式保存。测试覆盖有界来源选择、历史不可变性与浏览器保存流程。37 组连续本地演员请求的离线回放中，每组字符前缀均增长，渲染来源内容不变；这不代表已测得实际服务端缓存命中率。

正常完成还要求连续的调度状态：角色提交不代表所属导演运行已经结算。游玩在角色执行之间使用调度游标，正式正文版本阻止另一条执行流中晚到的旧角色草稿显示。已结算用量栏和已完整加载的记录停止后台读取；命令完成后补查未结算用量，不等待书库列表。用量栏预留高度。浏览器场景正常完成流式回合，检查随后连续 30 帧的几何稳定性、提交按钮恢复以及历史用量节点保留；仅验证中断不能证明正常完成稳定。

流式稳定性要求同一范围刷新时保留已加载的用量栏和展开记录。执行阶段切换时清空这些元素会压缩前文高度，干扰滚动锚定。范围标识不包含刷新触发值，但故事、角色和历史版本变化仍立即隐藏旧证据。正文草稿采用共享增量渲染器，保持标签引用和请求标识稳定。阅读列通过 ResizeObserver 在绘制前跟随增长，用户上翻时暂停；上一段延迟到达的滚动事件不能仅因下一段增大底部距离而取消跟随。[布局浏览器回归](../../../../apps/web/tests/reading-layout.e2e.ts)在真实模拟工具流的段落之间暂停，检查底部跟随、上翻阅读、段落 DOM 保留及桌面和窄屏对齐。组件回归覆盖用量栏和展开证据保留、延迟滚动事件和未完成 TeX。自然换行和最终 Markdown 解析仍可能改变正文高度。

[浏览器回归](../../../../apps/web/tests/independent-narrative.e2e.ts)检查阅读、搜索、存档输入及历史请求不变。[创作回归](../../../../apps/web/tests/authoring-recovery.e2e.ts)检查可见删除和导演连续请求。[可选真实模型检查](../../../../apps/web/tests/director-reasoning.e2e.ts)记录 DeepSeek V4 Flash 连续工具步骤的分析方式与语言，不写用户故事。观测到的推理为中文分析，没有角色内心独白，但一至三个短句的要求没有稳定遵守；提示词不能保证推理长度硬限制。

本决策细化了[故事书编辑器修复](2026-09-08-storybook-editor-and-reasoning.zh.md)。可视化最近删除恢复页仍不在本次变更范围内。

此前准备卡错误地放在整段正文末尾。现在准备记录有首次公开回合边界，按时间线插入；已结束的讨论保留独立位置。紧凑角色按钮每次展开一个记录，常驻讨论控制与较重的检查功能移入侧栏。视觉方向参考 [Linear 的辅助导航降噪](https://linear.app/now/behind-the-latest-design-refresh) 与 [Carbon 的渐进披露](https://carbondesignsystem.com/patterns/disclosures-pattern/)。skill 生成的营销展示页模式不匹配阅读工作区，因此未采用；颜色仍使用现有主题 token。本地排查同时发现：每个回放事件都深拷贝完整世界、重建请求时重复检查日志、读取原上下文前查询无关的当前作者视图。现在回放内部共享未变化的不可变实体并在返回时独立复制；记录检查跳过无关视图并复用已加载事件。测试覆盖历史顺序、视角切换竞态、侧栏关闭返回及既有恢复／导入契约。

运行中新建的吟游诗人暴露了另一处展示不一致：发言标题把登场时的场景称呼（包厢门外）当成了人物描述。游玩投影现在单独携带角色定义中的外观描述，流式与已完成标题均将其与姓名并列展示；视角控件保留原场景称呼。运行时创建回归覆盖三种玩家投影，浏览器素材收录流程验证常驻的收录标题与独立展开的选择区。收录仍创建独立待审阅草稿，不修改来源故事书。

故事书导入此前隐藏在书库折叠区中，选文件仅打开未经校验的本地编辑内容，导出则位于整个表单末尾。现在侧栏、书库及编辑器中的显式入口打开文件／粘贴面板，区分故事书与存档，提供确认、宿主校验错误以及失败重试时保留的草稿标识。故事书导入成功后打开已保存的新草稿，后续仍需审阅发布。导出使用已保存文档和资源，并采用可辨认的文件名。组件测试覆盖畸形文件包与失败输入保留；浏览器流程覆盖无效文件修正、存档恢复及故事书导出再导入，验证不覆盖原作或额外创建运行。
