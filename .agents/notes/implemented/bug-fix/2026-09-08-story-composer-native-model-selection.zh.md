# Agent Note: 故事输入区接入原生模型选择

Status: implemented

[English](2026-09-08-story-composer-native-model-selection.md) | 中文

## Problem

独立故事执行读取全局执行偏好。按会话工作的原生模型选择器无法写入该偏好，只有文本字段的设置表单也无法展示提供商目录与支持的推理等级。

## Decision

故事输入区声明 `model.selection.control`。模型选择插件使用共享的 Host 目录和所属组件提供的选择回调渲染原生菜单。叙事组件读取执行设置镜像，并以已读取的设置修订号提交修改。下一次执行读取保存的提供商、模型和推理等级。

## Alternatives considered

将会话选择器挂到技术性角色会话会修改错误的配置。复制菜单会重复维护键盘交互和提供商元数据处理。根作用域的展示插槽复用菜单，同时保留执行设置作为写入目标。

## Consequences

模型选择插件支持第二种选择所有者，无须导入叙事代码。故事输入区通过类型化插槽依赖该插件。选择失败时保留原先保存的值。浏览器回归切换模型和推理等级，并检查后续模拟执行请求。
