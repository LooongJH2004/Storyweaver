# Agent Note: 故事书编辑器与思维链指令

Status: implemented

[English](2026-09-08-storybook-editor-and-reasoning.md) | 中文

## Problem

独立 UI 将不完整的长书稿表单与重复的书库操作混在一起。原生按钮与剧情面板颜色不一致，新实例隐藏作者工具，上下文配方遗漏历史上的演员沉浸与导演简短思考指令。恢复通用设置并未恢复这些具体模块。

## Decision

故事书库与所选编辑器分开。编辑器提供单一的保存与发布栏、分区导航，以及所选角色的基础信息、私有认知、状态和风格标签。类型化控件覆盖初始记忆、目标、打算、认识、状态归属与可见范围；任意世界对象可以编辑，未涉及的属性保持不变。故事书编辑改变草稿，实例作者工具只改变所选运行。各页面使用共用主题配色。

不可变故事书版本保存可选的作者配方，新建实例时复制。默认配方末尾包含可编辑的演员沉浸与导演简短思考模块。措辞参考[历史角色扮演指令](https://github.com/victorchen96/deepseek_v4_rolepaly_instruct/)，使用当前工具协议。这些模块保留消息角色和完整内容，不附加自定义参考材料包装。宿主权限与工具校验仍具最终约束力。

已有配方若缺少这些模块，读取时保持不变。编辑器提供显式恢复，再通过修订校验保存。作者可以编辑、排序或关闭指令。思维链指令用于配置模型行为，不保证提供方内部推理的格式，也不把私有推理作为角色对白输出。

新实例立即显示角色、状态、风格、上下文、模型和记忆控制。AI 创作提供基础设定编辑及从发布版本创建实例的入口。尚未发布的故事书显示禁用的新建按钮和发布前提说明。

## Alternatives considered

**只修改 CSS。** 缺失字段与交叉重叠的编辑范围仍然存在。

**每次读取旧配方时插入指令。** 这会静默改变已存行为，且使作者无法有意省略模块。显式恢复保留已保存的选择。

## Consequences

[浏览器场景](../../../../apps/web/tests/authoring-recovery.e2e.ts)编辑并重载故事书、发布、新建实例、检查状态可见性，再通过模拟模型适配器记录演员最终请求。相邻的请求快照固定思维链消息。该场景还覆盖原生创作、本地素材、可移植资源、重写与移除。领域测试验证缺失模块的读取不改变存储，显式恢复与关闭会改变上下文。浅色与深色截图验证编辑器。[配方角色修正](2026-09-08-recipe-roles-and-turn-reading.zh.md)说明导演分析模式的准确标记、默认消息角色及有界真实模型观测。
