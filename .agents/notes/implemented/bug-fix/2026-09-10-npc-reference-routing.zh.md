# Agent Note：NPC 人物寻址与修正回执

状态：已实现

[English](2026-09-10-npc-reference-routing.md) | 中文

## 证据

本地后缀为 `a1076bf8d5a965c3b` 的演员会话记录了第 2 轮第 1 次、第 3 轮第 1 次 `npc_commit_turn` 失败，工具结果序号分别为 1236、2170。两次均在 `behavior[1].to[0]` 填入展示姓名；对应第 2 次提交改用已提供的人物引用后成功。第 2 轮仅修改收件人字段，第 3 轮还不必要地改写了动作正文。两次失败提交均未包含认知或状态来源引用。第 3 轮的私有思考主题已使用引用，不是失败原因。原始日志保留在本地，测试使用中性虚构文本。

## 决策

共享 NPC 策略、收件人 schema 示例和必需的 CURRENT PEOPLE 区段明确区分寻址引用、展示称呼和证据来源。私有思考主题保持描述性。语义提交在暂存角色修改前，校验行为目标、新状态定义中的人物字段、认知主题和讨论交接对象。拒绝时指出全部无效字段，整笔事务保持不变。唯一匹配的可见称呼得到对应 ref 修正提示；同名称呼仅展示当前观察者可见的候选。调用方仍须显式提交 ref。

## 替代方案与影响

自动按姓名寻址可能指错人物或暴露未知身份。动态工具 schema 枚举会随角色名单改变请求前缀。实现保留观察者局部查找和固定工具 schema，修正提示不包含隐藏的作者姓名或其他观察者的引用。既有作者配方和历史日志不变，共享运行时策略及必需上下文作用于已有实例的新请求。每次上下文增加有界的寻址指导，策略和 schema 增加固定开销；未测量服务端缓存收益或真实模型错误率降低幅度。

## 验证

领域回归重放连续两轮称呼错误，验证完整回滚、拒绝其他观察者的引用，并在保留描述性思考主题的同时接受修正后的收件人。组合错误用例检查准确路径和同名称呼。真实 Loader、SQLite 权威存储、Harness 循环与模拟模型回放验证修正工具回执进入下一次模型请求，请求协议快照固定策略和 schema。这些检查证明确定性的校验与重试行为，不代表真实模型永远不会产生无效参数。
