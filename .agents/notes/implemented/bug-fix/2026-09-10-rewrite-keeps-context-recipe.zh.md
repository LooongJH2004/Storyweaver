# Agent Note：重写保留已保存的上下文配方

Status: implemented

[English](2026-09-10-rewrite-keeps-context-recipe.md) | 中文

## 故障与决策

本地命令历史显示，包含用户 1000–1500 目标的 configuration.recipe 已成功提交，随后重写恢复操作却用原引导之前的默认配方替换了它。保存成功，但重新生成在组装请求前丢弃了已保存配置。重写保留当前上下文配方，同时恢复剧情。显式检查点恢复仍保留完整历史恢复的含义。其它世界与场景配置沿用所选历史状态。

## 持久化与交互

既有 history.restored 事件仅在重写时携带 preserveContextRecipe。提交投影与历史重放保留该恢复操作之前的配方，并推进配置修订号。此步骤与 epoch 失效处理原子完成，先于取消执行与继续生成。重试使用同一回执；存档校验接受所记录的选项。创作输入框旁提供保存应用操作与明确的未保存状态，滚动时配方保存栏保持可见。未保存的浏览器草稿不会静默应用。

## 验证

核心测试在原引导之后保存自定义导演配方与停用的演员模块，用同一命令重写两次，验证请求配置、相邻实例隔离、准确历史重放、存档导入及显式检查点恢复。真实 Harness 快照记录含有 1000–1500 的重写导演请求。浏览器覆盖通过输入框旁保存按钮编辑、重发引导、核对实际模型请求，以及刷新后重新打开编辑器。
