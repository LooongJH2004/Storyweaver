# Agent Note：故事正文段落渲染

Status: implemented

[English](2026-09-10-story-markdown-breaks.md) | 中文

## 问题

模型创作的故事文本在 JSON 解码后仍可能包含字面量转义分段符，Markdown 会将这些字符显示为正文。流式和正式正文还使用了不同的容器，卡片过紧的边距也削弱了段落分隔。

## 决策

剧情客户端拥有仅用于展示的规范化步骤，草稿与正式正文共用 Markdown 容器。该步骤转换连续转义换行符和简单换行标签，保留代码与路径的字面内容。现有 Markdown 渲染器继续负责语义格式和 HTML 安全。复制剧情采用规范化后的源文；持久化、导出和请求证据保持不变。

## 替代方案

全局解码字符串或启用原始 HTML 会改变技术证据、代码以及无关的 DSH 消息。重写已存剧情会丢失提交时的源文。本次修改限定在剧情展示层。

## 影响

单独的转义换行符可能属于路径或符号表达，因此保留字面形式。Markdown 段落语义将多个空行合并为段落边界。原生 Markdown 功能继续可用，并采用响应式排版。回归样例覆盖转义分段、代码保留、HTML 安全、流式结束以及真实浏览器中的间距。
