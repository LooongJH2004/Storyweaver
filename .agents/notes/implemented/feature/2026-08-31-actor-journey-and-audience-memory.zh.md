# Agent Note：角色心路历程与受众隔离的长期记忆

Status: implemented

[English](2026-08-31-actor-journey-and-audience-memory.md) | 中文

## 问题

Actor 的情绪、信念、关系、记忆、目标和意图能描述当前状态，却没有保存少数真正改变角色自我理解或后续选择的经历。重复的心理状态更新因此很容易被误当作角色成长。故事级长期记忆也曾让所有受众共用一份摘要，既可能把 Director 连续性泄露给 Actor，也可能把单一的所谓客观回忆强加给知识不同的角色。

## 决策

固定模型工具、有来源的持续事项及显式记忆替代由[来源连续性与固定工具](../architecture/2026-09-04-roleplay-source-continuity-and-fixed-tools.zh.md)规定。

Actor 在自己的私有 Session 中拥有带修订号的 `actor/turning-point` 事件。一次转折记录实质触发事件、Actor 的主观解释、重要度、状态、明确的前后变化，以及支撑它的私有状态事件引用。自主回合只能在单次 `npc_commit_turn` 事务中提交转折，并且必须同时存在实质性的信念、关系、目标或记忆变化。模型契约要求普通情绪和常规回应提交空数组；Host 会在事务写入前拒绝与现有未否定变化完全重复的转折。

模型生成的转折以“尚未定型”开始。PlayerAuthority 可基于准确修订完整替换内容，并将其标记为已内化、已逆转或已否定。已否定条目保留审计记录，但不再进入模型上下文。模型最多接收六条相关且未否定的转折，按重要度、状态，以及与当前目标、关系、记忆和近期行为的重合度选择。上帝视角角色面板提供完整时间线和编辑器；普通场景发言与行动继续作为独立会话事件展示。

故事长期记忆使用三个明确的受众层：`directorSummary`、`publicSummary` 和 `actorMemories`。Director 只接收导演摘要；Actor 只接收公共摘要及明确属于自己的那条记忆。Actor 层为空时绝不回退到 Director 内容。场景与篇章记忆仍须先提案再由玩家审核；Director 指导只要求在有意义的场景或篇章边界提出记忆。

持久化 Story 记忆结构直接改为新格式。旧 `summary` 与 `actorNotes` 字段不再接受，也不保留兼容读取器。

## 曾考虑的替代方案

**把每次情绪或信念更新都当作心路条目。** 这会复制原有重复心理流，使普通反应与持久角色成长无法区分。

**每回合结束后另行生成角色传记摘要。** 第二次模型调用会增加延迟，可能绕过 Actor 自身决策重新解释私有状态，并破坏一次规划、一次事务的回合契约。

**保留一份全局故事摘要并启发式脱敏。** 脱敏无法还原每名 Actor 真正感知并记住了什么；明确的受众归属字段才能强制表达缺失与隐私。

**删除被否定的转折。** 删除会隐藏玩家修正，也使事件重放无法解释某个旧解释为何不再影响 Actor。

## 后果

角色成长成为稀疏、主观、可审核且持久的记录，不再只是每轮状态流换名。玩家修改采用乐观修订，并立即影响下一次 Actor 上下文。上下文成本有明确上限，较旧条目仍保留在私有审计日志与玩家时间线中。

新的 Actor 事件扩展了持久化事件词汇；新的 Story 记忆对象也有意不兼容此前的预发布结构。转折生成仍依赖模型判断，因此 Host 强制事务耦合和完全重复拒绝，提示词负责更广义的语义阈值。
