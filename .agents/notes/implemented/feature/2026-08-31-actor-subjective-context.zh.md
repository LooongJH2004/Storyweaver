# Agent Note：不携带真伪标签的 Actor 主观上下文

状态：已实现

[English](2026-08-31-actor-subjective-context.md) | 中文

## 问题

故事书此前用 `knows`、`doesNotKnow`、`secrets` 和 `falseMemory` 保存 Actor 初始认知。“你不知道 X 为真”仍然把 X 告诉了模型；把一段记忆标为错误，也会让 Actor 模型获得导演层真相，再要求它表演无知。

## 决策

故事书 schemaVersion 4 用单一 `privateContext.perspective` 列表替代上述认知真伪分类。每一项只描述角色当前经历、记得或相信的内容，不附带真伪状态。角色无法获得的事实完全省略，只保留在 Director 可见的世界真相中。初始情绪、信念、关系、核心记忆、目标和意图继续结构化，因为它们描述可行动的私有状态，而不是判定某项世界事实是否客观正确。

Actor 规则只提供一条总引导：收到的感知、记忆与判断可能片面、过时或源于误解，但不会指出具体哪一项不可靠。真实运行上下文和上下文预览共用 `renderStorybookActorPrivateContext`，把 perspective 渲染成自然文本条目，并且不再序列化旧元数据键。

版本 3 故事书格式会被直接拒绝。《月影账簿》示例与本机活动故事书直接重写，不增加迁移器或兼容读取器。

## 后果

信息隔离成为上下文构建保证，而不是要求模型配合表演无知。Actor 可以真诚地活在错误确信中，而不会在另一个字段里同时收到纠正。作者必须只在 Director 所有的数据中保存隐藏真相，并从角色自身经历内部书写其初始视角。
