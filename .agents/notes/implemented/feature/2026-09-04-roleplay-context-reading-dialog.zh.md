# Agent Note: 角色扮演上下文阅读弹窗

Status: implemented

[English](2026-09-04-roleplay-context-reading-dialog.md) | 中文

## Problem

挂在对话消息旁的请求预览在滚动后可能失去可见的关闭入口。统一折叠的 JSON 字段隐藏了玩家理解回复所需的正文，也让传输参数与故事上下文占据同等显眼的位置。

## Decision

事件预览复用 Modal，固定标题区并仅让正文区域滚动。默认视图保留消息顺序，直接展示文本，测量六行预览并提供明确的展开操作。工具与参数使用独立视图。原始序列化请求和逐消息 JSON 始终可供检查，覆盖可读视图未解释的字段。数据仍按事件延迟加载；关闭不会取消成功结果的缓存，也不会因加载完成而重新打开弹窗。

## Alternatives considered

**右侧抽屉。** 保持对话可见有助于对照，但用户选择了更适合阅读长上下文的宽幅居中弹窗。

**按语义重新分组。** 将消息划分为角色设定、规则和剧情需要解释消息内容。保留发送顺序与原文可以可靠地展示模型收到的内容。

## Consequences

玩家无需逐条展开消息即可扫读上下文，并能在任意滚动位置关闭弹窗。弹窗会暂时遮住对话。它复用现有焦点和关闭行为，由预览自身负责锁定背景滚动。展示裁剪不改变已存上下文或模型输入。组件测试覆盖关闭、焦点、重试、缓存和字段保留。网页外观由用户手动验证。
