# Agent Note: 动态人物与个人认知

Status: implemented

[English](2026-09-06-dynamic-characters-and-knowledge.md) | 中文

## 问题

故事书固定名单会向 Actor 暴露陌生人的姓名，也让新增配角依赖编辑故事书。共用旁白混淆了世界事实、收到的证据与主观判断，后来的辨认还可能改变历史称呼。

## 决策

Story 在可恢复的世界状态中拥有独立人物库。模板定义只用于一次初始化，导演生成的人物得到不含姓名的身份并归当前故事。是否在场、是否被聚光和是否已有 Actor Session 分开管理；导演可以查找与创建人物，背景人群继续用旁白描写。定位变化保留身份、状态和记忆。

每个观察者拥有自己的认识线索与自然语言判断。线索可以代表可见外观、易容或尚未对应真人的传闻。认知保存证据、获知方式、判断态度和修订历史，听见一句话不等于证明其内容为真。共同常识可用于新人物，但不授予此前事件的受众资格；原作经历需要明确作者认知或实际感知证据。

Actor 日志拥有当前个人认知。`npc_commit_turn` 把认知、状态和行为放进同一次事务，Host 在接受任何操作前检查所有权、来源可见性、实体引用和准确修订。玩家纠正追加补偿修订，遗忘保留历史。Story 保存由提交投影得到的认知，用于查询、导出与检查点。记忆和目标保留已有生命周期，并可提供证据引用。

Actor 上下文使用观察者私有的人物引用与不含作者文字的状态字段引用，Host 解析行为目标。显式叙述标注使用当前视角称呼，已说出的对白保留原话。保留的作者来源携带当时的身份投影，表演事件携带历史称呼。上下文预览与实际请求共用渲染器，历史请求重建读取原始日志。

人物工作区提供场景浏览、作者编辑、个人判断与历史。收录基础故事书时先预览可复用设定，可选当前认知、状态或记忆，确认校验预览全文和两侧修订。引用的模板人物缺失时须先收录依赖；收录不安排出场，也不更新进行中的故事。

当前持久格式为故事书版本 6、Story 领域版本 12、清单版本 10、导出包版本 5 与检查点版本 3。旧格式校验失败，读取不会隐式转换。Actor Session 沿用现有事件格式，并增加明确可识别的认知事件类型。

## 考虑过的替代方案

**只在提示词中隐藏姓名。** 名单、工具、来源和历史标签中仍可能残留姓名或有语义的 ID。结构化视角投影与明确证据归属覆盖这些入口。

**为每个配角另建轻量模拟。** 这会重复维护行为和记忆生命周期。同一 Actor 机制可以保持休眠，直到人物确实需要独立回应。

**采用刚性知识图谱，或把感知直接当真相。** 自然语言判断允许传闻、矛盾、误信与不确定性，无需形式化蕴涵引擎。引用证据证明有权接触来源，不证明结论正确。

## 验证

无密钥[插件组合回放](../../../../packages/experimental/tool-director/tests/characters-knowledge.real.spec.ts)覆盖人物创建、按需演员、非法来源、原子行为、修订、冷重载、导入导出、模板收录与同 Session 撤回。[领域测试](../../../../packages/story/story/tests/knowledge.spec.ts)覆盖化名、易容、传闻、补偿、历史来源称呼以及 5,000 名离场人物。[浏览器测试](../../../../apps/web/tests/roleplay-characters-knowledge.e2e.ts)通过完整客户端执行真实人物与认知命令。

本地验证结果：42 个相关测试文件、239 项测试通过，完整浏览器交互测试通过。模板风格隔离和离场人物引用投影修正后的回归通过。Host／Client 类型检查、Web 构建和文档示例类型检查通过。仓库级文档门禁通过 25 项，7 项因已有无关欠项失败：审批插槽检查类型、翻译覆盖、Markdown 换行、导出 JSDoc、旧 Agent Note、文档字数和 story-home README 结构。真实模型认知情境已准备，尚未运行。

## 后果

Host 强制执行访问权限与修订规则，但自然语言推断和直接写出姓名仍须模型评测与人工审核。本次变更不引入离场演员持续调度、形式化推理引擎或默认原作知识。真实模型的姓名泄漏、无依据知识、重复人物、延迟与 token 指标需要单独的带凭证测试；离线测试不证明表演质量。
