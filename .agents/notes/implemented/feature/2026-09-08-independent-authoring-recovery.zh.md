# Agent Note: 独立创作与历史交互恢复

Status: implemented

[English](2026-09-08-independent-authoring-recovery.md) | 中文

## Problem

独立剧情应用需要完整的既有创作流程，同时不能重新让 Story 聚合成为业务权威。单独的 JSON 编辑器无法提供持久创作对话、本地素材、请求检查和同一已发布故事书的独立实例。原生会话挂载还错误地假设可选 Story 选择器始终存在。

## Decision

使用根作用域剧情工作区，在独立游玩和嵌入的原生对话之间切换。原生对话保留 Session 作用域、工具、权限控制和请求历史。只有组合中存在 Story 选择器服务时，才启用对应的绑定要求。共享导航和作者草稿属于根浏览器存储，切换创作 Session 不会拆散或丢失这些状态。

每个创作任务将原生 `storyweaver-author` Session 绑定到一本草稿。专用工具读取准确 schema、按修订保存草稿、预览发布内容并发布不可变版本。普通助手文本不会保存内容。默认值在初始化任务时复制，后续任务指导独立于默认值修改。明确选择的本地目录在任务创建时固定。任务缺少绑定时，工具守卫拒绝本地文件和终端操作；原生权限策略仍负责每项操作的授权。

故事书和实例使用不同的导航身份。加号从已发布版本创建全新实例。手工表单保留文档高级内容，可移植故事书导出保留资源字节。移除故事书隐藏创作入口，保留发布版本和实例。移除实例先追加移除事件并使执行失效，再取消技术运行，底层历史仍然保留。玩家要求重写将同一实例恢复到前一边界，并使用稳定重试命令身份开始新请求。

上下文来源顺序、角色和开关仍属于持久配置。规则、工具指导和推理语言可以使用独立模块。已有分组编排只在作者明确操作时拆分，读取不会改写它们。未保存的编排和设置在导航及刷新后保留。按需预览可包含待发送的导演要求；完整模型输入输出由原始请求检查器负责。

## Alternatives considered

**恢复聚合驱动的界面组合。** 这会重新引入独立架构已经移除的业务所有权。历史界面继续作为流程参考。

**将本地 JSON 作为权威草稿。** 通用文件写入无法强制执行草稿修订和不可变发布。本地素材与托管书稿文档分离。

**原地替换历史。** 原地重写会丢失可审阅的原版本，也无法隔离迟到的模型工作。补偿和执行代次失效保留这两个边界。

## Consequences

[AI 创作说明](../../../../docs/storybook-json-editing-guide.zh.md)分别说明原生故事书工具与外部 JSON 交付。其 v6 模板经过当前解析器及独立发布准备校验，回归用例拒绝旧 v4/v5 版本和私有状态结构。说明不再要求旧托管路径、自动发布或每轮创作调用终结工具。

进行中的创作任务在工作区顶部提供直接编辑提示词的入口。它展开已有设置表单并聚焦提示词，不另建编辑器或复制一份状态。保存反馈明确说明后续模型请求使用更新后的任务设置。浏览器测试在首轮回复后修改提示词和角色，刷新页面，再检查实际发送给模拟适配器的下一次请求。

插件重新加载时，嵌入对话的所有者可能被移除。在声明移除回调内立即恢复普通会话，会与尚待递归卸载的子插槽冲突。现在恢复操作在级联卸载后执行，并检查代次及插件生命周期，取消过期操作。注册测试覆盖两种加载顺序、同一时刻替换和退出；浏览器检查覆盖反复往返游玩与创作，并保留各自未发送的输入草稿。

支持的组合将原生工具、命令、权限和请求历史界面接入独立故事书工具。导演与演员执行仍使用受限工具。旧文件不转换，读取时不重新发布既有故事书，也不启用旧 Story 写入器。

无密钥测试验证原生创作、目录授权、文件输出、任务专用提示词、发布、独立实例、同实例重写和移除。领域测试验证重试身份、旧历史回放、实例隔离和设置修订。浏览器检查将编排草稿刷新、来源编辑与既有游玩流程一起验证。真实模型质量和性能仍未测量。

[游玩交互决策](2026-09-08-play-interface-recovery.zh.md)、[旧创作决策](2026-08-31-storybook-creation-mode.zh.md)和[旧独立实例决策](2026-08-31-independent-story-runs-and-deletion.zh.md)继续保留各自的阅读流程、托管文件与所有权理由。本决策替换其中与当前支持产品不同的接线；其余机制不合并、不归档。
