# Agent Note: 恢复以剧情为中心的游玩交互

Status: implemented

[English](2026-09-08-play-interface-recovery.md) | 中文

## Problem

独立后端切换同时把已有游玩界面替换成了业务表单。界面丢失角色回合分组和就地执行检查，把手工讨论控制放在主路径，并显示空人物名单与闲置控件。基于 mock 的验收遗漏了默认 provider 路由未被真实适配器注册的问题；通用执行失败文本又掩盖了原因。

## Decision

当前支持的独立创作与重写接线由[创作恢复决策](2026-09-08-independent-authoring-recovery.zh.md)说明。本文保留其余流程和所有权理由。

复用 dsh 原生侧栏外壳，包括折叠动画、紧凑栏、列宽拖动和设置。独立导航提供有类型的主操作与浏览、品牌插槽，不创建技术 Session。使用 dsh 的 Markdown、剪贴板、图标和 Modal 组件。字号精确遵循主题偏好，阅读宽度沿用原浏览器偏好键。模型选择、记忆审核和高级工具保留在草稿旁。实例标识放在提示中，不占据列表主要文字空间。

在 ui-narrative 内恢复故事标题、开场引导、已提交角色分组和底部输入区，保留独立应用与查询边界。仅面向玩家的发言人标识把显式检查路由到原始修订与演员；模型继续使用独立视角引用。保留真实姓名附注。实时诊断仍需玩家明确打开，并与已接受剧情分开。记忆和模型工具使用专用原生对话框；作者编辑和历史入口继续可用。

使用 base profile 随附的默认模型路由，并在 profile 测试中验证两者一致。保留当前执行的 turn-end 错误，不把 provider 失败替换成未提交剧情的提示。验证不存在的路由与错误传播无需调用模型。

回复宽度与输入栏高度分别记忆为浏览器偏好。两侧及顶部手柄捕获拖动并实时预览，松开后保存；Escape 或指针捕获取消时恢复原尺寸。方向键、Home/End、“布局”滑块及重置提供拖动之外的操作方式。ResizeObserver 根据可用空间限制显示尺寸，不覆盖大屏下保存的偏好。暗色采用石墨底色、细分隔与米白色主按钮，单层输入区优先保留书写空间。

## Alternatives considered

**恢复旧聚合驱动的产品组合。** 这会通过重新引入用户要求移除的业务依赖恢复旧 UI。旧组件作为设计参考保留。

**继续装饰表单式界面。** 共用配色与卡片不能单独恢复阅读流、语境化操作或有效的执行反馈。

**把模型草稿显示为已接受对白。** 这会误呈现尚未提交的输出。显式诊断保持两者的边界。

## Consequences

流式草稿与已提交回合共用同一个阅读列容器。原先独立的 900px 执行区域导致提交后横向跳动，打开人物面板时差异更明显。浏览器几何检查覆盖自定义宽度、人物面板与手机布局。对话和行动标注使用 14px 半粗主色文字。

思考使用共享折叠行，位于人物姓名下方、已提交正文之前；流式输出遵循相同顺序。玩家引导后常驻收起的导演调度行，因此没有旁白的初始调度仍能找到。查询边界截止到后续首个人物回合或下一条引导之前；分页从非引导内容开始时，在首条可见修订处保留导演入口。原位读取器通过注入的历史分页与详情查询工作，独立于全局作者检查选择；读取该边界最近一次模型回合的各个请求步骤，按需加载、分页补充早期步骤，并丢弃收起或切换范围后的迟到响应。工具参数属于请求记录，不代表剧情变更已成功。


书库呈现遵循相同的故事阅读层级：翻开书页标识、简洁欢迎区、AI 与手工创作入口，以及带发布状态和既有运行入口的文字书封。导入使用支持键盘的折叠区。书封从故事书读取标题与简介，并使用本地矢量图形，无需远程素材或生成剧情内容。浅色与深色令牌、窄屏布局和减少动态效果规则归剧情呈现层所有。

通过不依赖 Cordis 的 `TranscriptCard` 渲染器恢复 `RoleplayEventView` 的事件卡片结构和八组人物色调。人物称呼与已接受内容仍归独立查询所有。人物认知和记忆审核共用原生弹窗；完整编辑使用分区导航及指定对象的工作区。展开实时诊断即开始订阅，无需再勾选一层开关。已记录的推理使用原生折叠组件。

输入区立即显示请求状态，失败保留正文，并沿用原输入区的 Enter／Shift+Enter 与输入法保护。导演准备事务同时记录仅供玩家查看的指导消息；回放、补偿恢复和存档校验覆盖这类记录，不把它作为演员证据。浏览器重载保留实例选择，视角从旁观恢复。工具指导明确区分 finish 的顶层字段与演员的视角引用；这属于协议指导修正，不代表已经测量模型质量。

游玩主路径不再要求手工建立讨论、为记忆审核跳转整个作者工作区或阅读技术修订编号。逐回合检查使用已有的防迟到响应 API 镜像。对话框保留键盘焦点、Escape 关闭和未发送正文。测试覆盖原生工具失败传播、默认路由一致性、原始请求检查、记忆审核、草稿保留和响应式布局。同实例玩家要求重写遵循链接中的恢复决策。完整沉默回合历史与连续跨页剧情加载不属于本文的阅读决策，有界分页继续可用。真实模型表现与玩家评价仍独立于无密钥检查。
