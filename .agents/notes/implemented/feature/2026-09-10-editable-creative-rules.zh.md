# Agent Note：可编辑的创作与推进规则

Status: implemented

[English](2026-09-10-editable-creative-rules.md) | 中文

## 决策

performance 上下文模块负责各接收方的篇幅、推进与表演指导要求。故事和故事书编辑器展示其文本、启用状态、消息角色与顺序，并提供恢复默认操作。表演风格编辑器提供通向这些默认设置的入口。固定 NPC 和导演协议保留提交、知识及控制权规则，不重复规定创作篇幅。停用模块会从后续请求中移除其指令；其它显式编写的表演风格或规则模块仍然生效。

## 解析与作用范围

resolveContextRecipe 在已有配方缺少 performance 时投影出继承的默认模块，不写入存储。显式文本（包括编辑中暂时为空的草稿）和停用模块都会保留。作者视图、已保存预览与执行使用同一投影。保存通过既有的带修订号配置命令落实界面所见模块。由于缺失表示继承，界面提供停用而非删除。故事书编辑仍是面向未来发布运行的草稿变更；实例编辑只影响本次运行。历史执行日志保留实际发送的上下文；用当前默认值重新生成缺少模块的旧配方，不能替代当时的请求记录。

## 验证

核心测试覆盖继承默认值、精确自定义角色与文本、停用模块、实例隔离和重放。真实 Harness 请求快照包含创作模块；恢复后的演员请求体现编辑与停用结果，不残留旧篇幅规则。导演请求快照包含作者替换文本。客户端测试覆盖两种接收方的编辑与恢复。浏览器回归编辑、保存、刷新并预览导演规则，停用演员规则，检查两者独立的上下文结果。这些检查证明配置已送达，不保证文学输出的实际长度。
