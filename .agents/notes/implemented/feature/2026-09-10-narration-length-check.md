# Agent Note: Narration length before publication

Status: implemented

English | [中文](2026-09-10-narration-length-check.zh.md)

## Decision

The optional context recipe narrationLength field owns enabled, minimum and target settings. Both editors expose integers from 1 to 10000, with target at least minimum. Absent settings preserve advisory prose instructions. Enabled limits appear in a recorded director context section and override textual length suggestions; target is not a maximum. The [editable creative rules decision](2026-09-10-editable-creative-rules.md) continues to own prose guidance.

## Publication and revision

DirectorCommands stages short observations as author drafts without publishing facts or perceptions. Receipts contain the draft, count, deficit and revision. director_revise_narration appends only new paragraphs or replaces the complete prose. Optional settlement fields replace the complete factual payload when prose changes events. Stale revisions and other writes while a draft is pending are rejected. Final world validation and publication share one transaction. Internal observations without narration are exempt.

The counter parses Markdown after observer identity projection and counts Unicode letters and digits individually. Punctuation, whitespace, formatting, reference definitions and destination URLs do not contribute. This defined character metric does not assess literary quality or semantic consistency.

Two insufficient revisions end the attempt with a visible failure and a retained unpublished draft. The reader preserves one draft node and ignores already incorporated append arguments. Authors can review the text and adjust saved limits before retrying; a new execution does not automatically resume an earlier attempt's draft.

## Consequences and verification

Host counting replaces unreliable model estimates. Draft staging prevents repeated world settlement. Each revision adds one model request and a receipt proportional to draft length, using the same logged execution history. New tools change the stable prompt prefix; limit edits change the numeric context section.

Core tests cover counting, append, replacement, duplicate calls, stale revisions, blocked dispatch, exhaustion, replay and archive import. Real Loader tests verify feedback in actual subsequent requests, one combined publication and bounded failure. Client tests cover numeric validation and stable draft nodes. Browser checks save, reload and preserve limits through rewriting, then expand short prose through the real tool path.

The numeric instruction section reserves its character budget before optional history is selected. Appending it after history had already consumed the full budget caused world-intervention refreshes to fail. Regression coverage fills the budget with an intervention, retains saved limits, completes director execution, and verifies that retrying the same intervention does not duplicate world facts. Required-only overflow still fails explicitly.
