# Agent Note：旁白发布前字数校验

Status: implemented

[English](2026-09-10-narration-length-check.md) | 中文

## 决策

上下文配方的可选 narrationLength 字段保存 enabled、minimum 和 target。两个编辑器均提供 1 至 10000 的整数输入，目标不得低于最低值。未配置时保留文字提示词的建议语义。启用的要求进入有记录的导演上下文模块，优先于文字篇幅建议；目标不是上限。[可编辑创作规则决策](2026-09-10-editable-creative-rules.zh.md)继续负责文字指引。

## 发布与修订

DirectorCommands 将短旁白暂存为作者草稿，不发布事实或感知。回执包含草稿、计数、差额和修订号。director_revise_narration 只追加新段落或替换完整正文。正文改变事件时，可选 settlement 字段替换完整事实载荷。过期修订与草稿待处理期间的其他写入被拒绝。最终世界校验与发布共用一个事务。没有旁白的内部观察不受字数限制。

计数器在观察者身份投影后解析 Markdown，逐一统计 Unicode 文字和数字。标点、空白、格式、引用定义和链接目标地址不计。这种明确的字符度量不评估文学质量或语义一致性。

两次修订仍不足时，执行以明确失败结束，保留未发布草稿。阅读界面保留一个草稿节点，忽略已经合并的追加参数。作者可以查看正文、调整已保存要求后重试；新执行不会自动续接上次尝试的草稿。

## 影响与验证

程序计数替代不可靠的模型估算。暂存草稿避免重复世界结算。每次修订增加一次模型请求和与草稿长度成比例的回执，使用同一执行的记录历史。新工具改变稳定提示词前缀，数值编辑改变字数上下文模块。

核心测试覆盖计数、追加、替换、重复调用、过期修订、阻止提前调度、次数耗尽、回放和归档导入。真实 Loader 测试验证实际后续请求中的反馈、合并后一次发布与有界失败。Client 测试覆盖数值校验和草稿节点稳定性。浏览器检查数值保存、刷新、重编保留，再通过真实工具路径扩展短稿。

数值指令模块在筛选可选历史前预留字符预算。此前先让历史占满预算再追加该模块，会导致世界干预后的刷新失败。回归测试用干预内容填充预算，验证已保存字数设置保留、导演执行完成，以及重复提交同一干预不会重复创建事实。必需内容本身超过预算时仍明确报错。
