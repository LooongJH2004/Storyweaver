# Agent Note: 按故事书隔离的共享创作配置

Status: implemented

[English](2026-09-10-shared-creative-settings.md) | 中文

## Problem

同一本故事书的实例需要复用旁白字数和创作指令，同时保留自己的独立配置。不同故事书即使 JSON 标识或标题相同，也必须互不影响。

## Decision

共享范围绑定故事书库的 BookId，通过实例固定的发布版本查找所属故事书。共享值、不可变版本和幂等回执存入各书独立的命名空间；拒绝实例向另一故事书发布配置。[系统初始化默认值](2026-09-11-context-defaults-and-character-voice.zh.md)单独为新书提供初始副本，不让已有书或实例订阅它。

共享五个原子模块：旁白字数、导演创作指令、演员创作指令、导演思考指令、演员思考指令。不共享人物、世界状态、记忆、模型配置或完整上下文配方。

每个实例初始保留独立副本。每个模块可使用本地保存值、固定故事书版本值，或明确选择的共享版本。跟随时保留独立备份；切回独立时恢复它。复制共享为独立配置会明确替换备份并停止跟随。

发布要求明确选择模块且共享版本一致。从实例发布还校验实例保存版本和准确的已保存值。发布不改变该实例的来源选择。界面按故事书分别保留共享草稿；过期草稿需重新审核才能发布。

跟随更新在下一次被接受的玩家操作边界原子应用。共享值转为普通配方快照，与玩家操作一起提交。上下文校验在持久化之前运行，因此校验失败不会部分接受世界干预或更新配置。执行中的请求保持已应用快照。

恢复和存档导入保留实际配置值，并暂停共享跟随。恢复跟随需要明确保存来源。故事书 JSON 导出普通配方值，不导出动态订阅。复制共享模块到故事书草稿只改变草稿，保存并发布后才用于新实例。

## Alternatives considered

- 应用级全局动态共享：不同故事的配置不应互相影响，因此拒绝；初始化副本属于独立能力。
- 立即更新所有实例：会覆盖独立创作并在请求执行中改变配置，因此拒绝。
- 每次模型请求动态读取：会让历史重放依赖今天的共享值而非当时接受的快照，因此拒绝。
- 替换完整配方：结构性上下文配置和自定义章节不属于本次共享契约，因此拒绝。

## Consequences

侧栏提供本书共享设置入口，上下文编辑器在支持的模块旁提供来源选择。跟随值必须先切为独立才能编辑。共享发布和实例来源变更是两个操作；共享模块缺失时不能静默跟随。

[核心测试](../../../../packages/story/roleplay-core/tests/world.spec.ts)覆盖故事书隔离、版本冲突、回滚、独立值恢复、延迟跟随及恢复/导入后的暂停。[浏览器测试](../../../../apps/web/tests/player-performance.e2e.ts)通过实际发布配置验证共享发布和独立/跟随切换。纯模块定义是浏览器可用的叶子模块，持久化和命令留在宿主。
