# Agent Note: 后台记忆整理队列

Status: implemented

[English](2026-09-13-background-memory-queue.md) | 中文

## Problem

此前记忆整理虽是独立模型调用，仍由角色结束、讨论收尾和导演续写等待，并占用前台执行记录。
直接移除 await 会与下一轮的修订校验及技术会话发生冲突。

## Decision

产品组合向演员与导演运行时注入持久化先进先出队列。前台只提交来源批次，不等待模型整理。
队列拥有一个后台工作器和独立 Harness 记忆会话，不打开角色表演或导演调度记录。
未注入队列的直接运行时调用仍保持其显式同步行为。

任务按实例和演员或导演隔离，沿用可配置的来源阈值与批次数限制；讨论结束可收录不足阈值的批次。
已被排队、运行、待接入或失败任务占用的来源不重复派发。任务开始执行时冻结上下文与记忆修订。
模型仅能提交记忆和读取该视角的原始依据，不能发言、结算行动、修改目标或世界状态。

结果先保存为待接入，仅在前台演员和导演空闲时写入。历史世代改变则取消任务；个人记忆修订
改变则标记过期，要求重新整理。新增世界事件本身不会覆盖已冻结的输入。结果仍遵循当前审核
或自动生效策略，原文仍可读取。导入存档时独立重算预期的记忆变更，禁止通过后台命令修改其他剧情。

队列保存在原 SQLite 通用记录表的独立技术命名空间，排队与状态更新不推进故事修订，接入结果
才产生剧情提交。重启后恢复中断任务；稳定的接入命令标识防止崩溃后重复写入。整理失败不阻塞剧情。
未完成的技术任务仅属于当前 Home，不随剧情存档迁移；已接入的提案和原生执行证据正常导出。

“后台记忆”面板独立读取任务简表，点击时才读取结果全文，显示排队、整理、待接入、已接入、
失败、取消和过期状态，并支持对失败或过期任务重新整理。不加载作者工作区或上下文预览。
原生用量与导出执行证据包含后台会话。memoryQueueIntervalMs 控制轮询，默认 1000 毫秒。
单个工作器限制新增模型并发，但不消除提供方限流与 token 成本。

此方案部分替换[群组讨论、感知与记忆实现](2026-09-12-discussion-perception-memory.zh.md)
中的阻塞式整理流程。旧说明仍负责独立的感知、记忆、隐私及评测决策，因此保留而不整体归档。

## Verification

定向回归通过 327 项，浏览器流程通过；DeepSeek Flash low 原生探针将未结算行动保留为尝试。隔离探针的固定前台输入约 97 毫秒返回，后台原生生成及接入约 5.99 秒完成，后台输出 731 token。固定前台输入不能代表普通模型表演速度。证据见 .tmp/background-memory-full-regression.log、.tmp/background-memory-browser.log 和 .artifacts/pending-attempt/2026-09-12T23-14-04-409Z/review.json。

队列测试覆盖整理期间继续剧情、延迟接入、来源去重、玩家修改冲突、重新整理、中断恢复、
历史回退及存档往返。实际 Loader 和执行器组合验证讨论及导演先结束，随后整理记忆，再检查
结果、原生用量、导入证据和后续回忆。独立面板测试验证预览和重试不加载作者工作区。
未完成行动的原生探针已改为等待后台队列，并单独记录前台耗时。

## Alternatives considered

**直接移除现有 await。** 旧运行时仍占用表演执行记录和严格的修订校验，下一轮会与它冲突或使它失效。

**模型完成后直接修改实时上下文。** 结果可能早于玩家纠正或历史回退，暂存及校验接入边界才能保留新进展。

**完成即自动批准。** 后台调度不提高记忆真实性，因此保留原有的个人审核策略。

## Consequences

前台结束不再包含后台模型耗时。下一轮可能早于新记忆完成，此时继续使用已有原文与有效记忆。
失败和冲突独立展示。前后台仍共享提供方资源，这是并发调度，不是模型服务端的优先级预留。
旧同步整理夹具仍保留为明确的参考覆盖；假定角色结束即完成整理的原生夹具需要改为等待队列状态。
