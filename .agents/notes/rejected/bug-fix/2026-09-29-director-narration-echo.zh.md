# Agent Note: 避免导演旁白重播已接受的演员回合

Status: 本轮未通过验收；真实 Agent Role Play 回放后已撤回该单行指导改动

[English](2026-09-29-director-narration-echo.md) | 中文

## 问题

在厨房湿信的真实回放中，诺诺的动作和台词已经对玩家可见，导演随后仍重新叙述了他收纸的动作，并引用了同一句台词。这让同一瞬间播放两遍，还把外貌标签带进了正文。更早的厨房回放也重复了收纸动作。现有[导演表演指导](../../implemented/feature/2026-09-10-director-performance-cues.zh.md)已反对逐步重述，但 `director_observe.narration` 字段仍要求每个可观察事件都写成充分展开的段落。

## 决策

提案只修改 `director_observe.narration` 字段说明，要求描写新出现的可感知世界结果及后果。真实回放未达到预登记的接受条件，随后已恢复旧版源码文案与快照。

## 曾考虑的替代方案

- **在通用导演表演指导中再次写入禁令：**该指导已有这项要求，但更贴近调用的工具字段仍推动充分展开的复述。
- **机械屏蔽相似文字：**仅靠文字重叠无法区分冗余重播与必要的新后果交代，还可能藏掉重要结果。
- **让所有结算旁白都很短：**重大转场和已配置的篇幅偏好仍需要展开空间。

## 后果

聚焦的 schema 测试核对了候选的模型可见字段说明。首组真实供应商 A/B 不支持原假设：基线 A1 没有重复旁白，候选 B1 却重述了诺诺已显示的收纸动作。两次运行几乎耗尽预登记的 token 预算，所需重复样本和留出场景未运行。[本轮记录](../../../../.artifacts/storyweaver-evolution/round2-director-echo-registration.md)保存了证据不完整的状态和具体失败。需要下一轮独立实验才能声称文风改善。
