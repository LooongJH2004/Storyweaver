Use `packages/story/roleplay-services/tests/longform-performance.e2e.ts` as the real API entry path. Check its `review.json`, `story-archive.json`, and recorded request events. The existing artifact and usage helpers can preserve partial results. Missing archive, request source, or usage makes evidence `incomplete`; never silently substitute a saved prose excerpt. Record elapsed time, native usage, failures, and costs if available. `postflight` checks native cumulative usage in every actor case and in `director.usage`; do not add case usage values together because each is cumulative for the same story. The credential store is provided by environment at execution time; the run pack records only whether a reference exists and never copies it.

Randomize labels before blind review. Show complete scenes with relevant preceding turns, director `finish.actors`, stage directions, facts, and actual model-visible request sources. Use [the eight-dimension rubric](rubric.md) with line or event IDs for each score and classify likely cause as actor, director, authored scene, examples/summary, sampling, or facts/memory. Separate narration from dialogue. Compare what characters *claim–why–do*, not word frequencies alone. An independent blind reviewer resolves disputed scores with explicit evidence; retain disagreement if unresolved.

Treat leaked private knowledge, overridden player decisions, rewritten settled facts, missing/incorrect model-visible input, or mismatched fixture/build/config as hard failures. Mark the affected sample `invalid` for comparison and fix the setup or reject the candidate as appropriate; never offset these with style scores. Mark collection failures `incomplete`. A valid comparative result is `accept` only if the registered multi-scene criterion passes across independent repeats, no hard failure rises, and the holdout supports the finding. Use `reject` when a valid result fails the criterion or regresses. Use `inconclusive` when samples, variance, missing evidence, or reviewer disagreement cannot support either conclusion. Record uncertainty and rerun only within the pre-registered budget; otherwise close the round and register a new one.
